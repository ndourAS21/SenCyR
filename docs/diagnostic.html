Auto-diagnostic de cyber-résilience

Appréciation qualitative et déclarative, sans valeur officielle. Les règles appliquées sont celles de la grille (échelle, R3, R5, R6) décrites dans la page Méthode. Les réponses saisies ne quittent pas votre navigateur.

1. Saisie, facteur par facteur

Comment remplir
  • Niveau : émergent (inexistant, annoncé, en projet ou partiel), structuré (en place et formalisé), consolidé (coordonné, durable, ajusté dans le temps), ou « non évaluable » si aucune source fiable ne permet de l'apprécier. Une annonce ou un projet ne dépasse pas « émergent » (R1).
  • Sources A, B, C : nombre de sources qui fondent le niveau, selon les niveaux de fiabilité de la grille (voir Méthode). Les sources D ne comptent pas.
  • Absence de trace (R2) : le niveau repose sur l'absence de trace publique d'un dispositif public par nature.
  • Source indirecte : le niveau n'est approché que par des indicateurs indirects.
  • Sources convergentes : les sources concordent sur le niveau attribué, pas seulement sur l'existence d'un dispositif ou d'une intention. Décoché, le niveau repose sur une source non recoupée (R3).
  • Aspects : un facteur décomposé en aspects prend le niveau de son aspect évaluable le moins avancé (R5) ; son niveau est calculé, pas saisi.
  • Exposition et faisabilité (R6, facteurs émergents) : des incidents récents montrent l'urgence ; une réforme en cours offre un levier. La portée se déduit des fonctions de résilience auxquelles le facteur contribue.
